Shoper Ecosystem AI Chat Agent

A context-aware intelligent support chatbot widget integrated with a Python RAG backend running the Qwen 3.5 Cloud model.

Python RAG Backend

The backend serves RAG queries using Cosine Similarity calculations over your SQLite database. It runs a FastAPI web server on port 8000.

# Run the FastAPI server python python/chatbot.py
Checking server...

Document Ingestion

Index documents in the documents/ directory to construct your SQLite vector database. Supports PDF, TXT, and Markdown files.

# Run document indexing python ../ingest.py

Currently matches embeddings generated by nomic-embed-text.
